## ขั้นตอนที่ 5: ตั้งค่า Gemini API สำหรับระบบวิเคราะห์งาน

ส่วนนี้ตั้งค่า key ไว้ที่ Google Apps Script เท่านั้น **ห้ามใส่ API key ใน `README_SETUP.md`, `app-config.js`, HTML, GitHub หรือส่งผ่านแชต** ผู้ที่เคยเปิดเผย key แล้วควรลบ key เดิมใน Google AI Studio และสร้าง key ใหม่ก่อนใช้งาน

### Step 5.1: เพิ่ม Script Properties

1. เปิด Apps Script ที่ผูกกับ Google Sheet แล้วกด **Project Settings** (รูปเฟือง)
2. เลื่อนลงไปที่ **Script Properties** แล้วกด **Add script property**
3. เพิ่มค่าต่อไปนี้:

| Property | Value |
| --- | --- |
| `GEMINI_API_KEY` | API key ใหม่จาก Google AI Studio |
| `AI_TEACHER_PASSWORD` | รหัสผ่านเฉพาะสำหรับบันทึกเฉลย AI ตั้งรหัสที่คาดเดายากและไม่ใช้รหัสผ่านล็อกอินหน้าเว็บ |
| `GEMINI_MODEL` | ไม่บังคับ; ค่าเริ่มต้นคือ `gemini-2.5-flash` |

กด **Save script properties** หลังเพิ่มค่าแล้ว อย่าบันทึกค่าจริงลงใน README หรือ repository และตรวจสอบ quota/ค่าใช้จ่ายของ Google AI Studio ก่อนเปิดให้ใช้งานจริง

### Step 5.2: อัปเดต Apps Script deployment

1. คัดลอกโค้ดฉบับล่าสุดจาก `Code.gs` ไปแทนที่ใน Apps Script แล้วกด **Save**
2. กด **Deploy → Manage deployments** แล้วกดไอคอนแก้ไขของ Web App
3. เลือก **New version** แล้วกด **Deploy**
4. ใช้ Web App URL เดิมใน `app-config.js` หาก URL เปลี่ยน ให้อัปเดต `appsScriptUrl` ด้วย
5. หากระบบถามสิทธิ์เพิ่ม ให้ตรวจสอบและอนุญาต Google Sheets, Google Drive และการเชื่อมต่อภายนอกตามที่ Apps Script ขอ

### Step 5.3: Actions ที่ backend รองรับ

- `saveAiAssignmentConfig`: บันทึก `assignmentId`, `question`, `referenceText`, `rubric`, `feedbackPolicy` และอาจแนบ `referenceImageData` กับ `referenceImageMime` โดยต้องส่ง `teacherPassword` ที่ตรงกับ `AI_TEACHER_PASSWORD`
- `analyzeAssignmentDraft`: รับ `assignmentId`, `subject`, `room`, `student` และอย่างน้อยหนึ่งอย่างระหว่าง `answerText` หรือ `answerImageData` (ชนิดภาพ `answerImageMime` รองรับ PNG, JPEG และ WebP) แล้วส่งคำแนะนำกลับโดยไม่บันทึกเป็นงานส่ง

ภาพรองรับขนาดไม่เกินประมาณ 3 MB ต่อภาพ รูปเฉลยจะเก็บในโฟลเดอร์ส่วนตัวบน Drive และไม่ถูกส่งออกใน `getAll` เมื่อเรียกวิเคราะห์ครั้งแรก Apps Script จะสร้างชีต `AIConfig` และโฟลเดอร์เก็บรูปเฉลยส่วนตัวให้อัตโนมัติ

**สถานะปัจจุบัน:** เพิ่ม backend actions แล้ว แต่หน้าเว็บยังไม่มีฟอร์มครูสำหรับตั้งเฉลยหรือปุ่มนักเรียนสำหรับวิเคราะห์/ยืนยันส่ง การตั้งค่า API key และ Deploy เพียงอย่างเดียวยังไม่ทำให้ปุ่ม AI ปรากฏ ต้องเชื่อมหน้าเว็บเข้ากับ actions ข้างต้นก่อน

**ข้อควรระวังด้านความปลอดภัย:** Web App ที่เปิดให้ `Anyone` เรียกได้ยังไม่ใช่ระบบยืนยันตัวตนที่แข็งแรง ข้อจำกัดการเรียก AI ในโค้ดเป็นเพียงการป้องกันเบื้องต้น และข้อมูลคำตอบจะถูกส่งไปประมวลผลกับ Google Gemini อย่าใช้กับข้อมูลส่วนบุคคลที่ไม่จำเป็น

## 1. โครงสร้างไฟล์ในระบบ

- 📄 **`app-config.js`** : ไฟล์ตั้งค่ากลางหลัก (ชื่อโรงเรียน, ครูผู้สอน, ภาคเรียน, รายวิชา, รายชื่อนักเรียนเริ่มต้น, รหัสผ่านครู)
- 📄 **`Code.gs`** : โค้ดหลังบ้านสำหรับคัดลอกไปวางใน Google Sheet (Apps Script Backend)
- 📄 **`ตัวอย่างไฟล์นำเข้ารายชื่อนักเรียน.csv`** : ไฟล์แม่แบบ CSV สำหรับใช้กรอกและนำเข้ารายชื่อนักเรียน
- 📄 **`index.html`** : หน้าเว็บหลักสำหรับนักเรียนส่งงาน และแดชบอร์ดครูผู้สอน
- 📄 **`firebase-config.js`** : เชื่อมต่อและดึงค่าจาก `app-config.js` อัตโนมัติ

## ขั้นตอนที่ 1: การติดตั้ง Google Apps Script (`Code.gs`)

### Step 1.1: สร้าง Google Sheet ใหม่
1. เปิดเว็บไซต์ [Google Sheets](https://sheets.google.com) แล้วกดสร้างสเปรดชีตใหม่ (Blank Sheet)
2. ตั้งชื่อไฟล์ตามต้องการ เช่น `ระบบติดตามการเรียน_เทอม1_2569`

### Step 1.2: เปิดเครื่องมือ Apps Script
1. ที่แถบเมนูด้านบนของ Google Sheet เลือกเมนู **"ส่วนขยาย" (Extensions)** -> **"Apps Script"**
2. หน้าต่างการเขียนโค้ด Google Apps Script จะเปิดขึ้นมา

### Step 1.3: วางโค้ด `Code.gs`
1. ลบโค้ดเดิมทั้งหมดในหน้าต่าง Apps Script ออก
2. เปิดไฟล์ [Code.gs](file:///c:/Users/nutta/physics-web-2569/Code.gs) ในโปรเจกต์ คัดลอกโค้ดทั้งหมด (Ctrl+A -> Ctrl+C)
3. นำโค้ดไปวางในหน้าต่าง Apps Script (Ctrl+V)
4. กดไอคอน 💾 **บันทึก (Save)** ที่แถบด้านบน

### Step 1.4: เผยแพร่เป็นเว็บแอป (Deploy as Web App)
1. กดปุ่มสีน้ำเงิน **"การจัดวางใช้งาน" (Deploy)** ที่มุมขวาบน -> เลือก **"การรายการใหม่" (New deployment)**
2. คลิกรูปเฟือง ⚙️ ด้านซ้ายคำว่า Select type -> เลือก **"เว็บแอป" (Web app)**
3. ตั้งค่ารายละเอียดดังนี้:
   - **คำอธิบาย (Description)**: `Classroom Backend API v2`
   - **เรียกใช้ในฐานะ (Execute as)**: `ฉัน (Me)`
   - **ผู้มีสิทธิ์เข้าถึง (Who has access)**: **`ทุกคน (Anyone)`** *(⚠️ สำคัญมาก: ต้องเลือก "ทุกคน" เพื่อให้นักเรียนและระบบส่งงานเข้ามาบันทึกข้อมูลได้)*
4. กดปุ่ม **"จัดวางใช้งาน" (Deploy)**

### Step 1.5: อนุญาตสิทธิ์การใช้งาน (Authorize Permissions)
1. ป๊อบอัพอนุมัติสิทธิ์จะขึ้นมา ให้กดปุ่ม **"อนุมัติการเข้าถึง" (Authorize access)**
2. เลือกบัญชี Google ของคุณ
3. หากหน้าจอเตือน "Google hasn't verified this app" ให้คลิกคำว่า **"Advanced" (ขั้นสูง)** ที่ด้านล่างซ้าย
4. คลิก **"Go to Untitled project (unsafe)"** (หรือชื่อโปรเจกต์ของคุณ)
5. กดปุ่ม **"Allow" (อนุญาต)**

### Step 1.6: คัดลอก Web App URL
1. เมื่อกระบวนการเสร็จสมบูรณ์ จะมีป๊อบอัพแสดงผล ให้คัดลอกข้อความในช่อง **URL ของเว็บแอป (Web App URL)**
   *(รูปแบบจะมีลักษณะดังนี้: `https://script.google.com/macros/s/AKfycb.../exec`)*

## ขั้นตอนที่ 2: การตั้งค่าไฟล์คอนฟิกกลาง `app-config.js`

เปิดไฟล์ `app-config.js` ในโฟลเดอร์โปรเจกต์ด้วยโปรแกรมแก้ไขโค้ด แล้วนำ URL ที่คัดลอกมาวางในช่อง `appsScriptUrl`:

```javascript
const APP_CONFIG = {
  // 1. ข้อมูลทั่วไปของโรงเรียนและผู้สอน
  schoolName: "โรงเรียนสนมวิทยาคาร",
  teacherName: "ครูณัฐพล สุขยานุดิษฐ",
  department: "กลุ่มสาระการเรียนรู้วิทยาศาสตร์และเทคโนโลยี",
  academicYear: "ปีการศึกษา 2569 (ภาคเรียนที่ 1)",
  teacherPassword: "physics2569", // รหัสผ่านล็อกอินเข้าหน้าแดชบอร์ดครูผู้สอน

  // 2. ลิงก์ Web App URL จาก Google Apps Script (ที่คัดลอกจากขั้นตอนที่ 1.6)
  appsScriptUrl: "https://script.google.com/macros/s/AKfycb.../exec",

  // 3. รายชื่อวิชาที่เปิดสอนในเทอมนี้
  subjects: ["ฟิสิกส์ 3", "ฟิสิกส์ 5"],

  // 4. รายชื่อนักเรียนเริ่มต้น (หากใช้วิธีนำเข้าผ่าน CSV ไม่จำเป็นต้องแก้ตรงนี้)
  students: {
    'ฟิสิกส์ 3': {
      'ม.5/1': ['นายกนกศักดิ์ สีงาม', 'นายชยกร สมพันธ์', ...]
    }
  }
};
```

## ขั้นตอนที่ 3: การนำเข้ารายชื่อนักเรียนด้วยไฟล์ CSV

หากต้องการอัปเดตรายชื่อนักเรียนยกโรงเรียนในเทอมใหม่:

1. คุณสามารถดาวน์โหลดไฟล์แม่แบบตัวอย่าง CSV ได้ 2 วิธี:
   - เปิดไฟล์ [ตัวอย่างไฟล์นำเข้ารายชื่อนักเรียน.csv](file:///c:/Users/nutta/physics-web-2569/ตัวอย่างไฟล์นำเข้ารายชื่อนักเรียน.csv)
   - หรือเข้าหน้าครูบนเว็บ แล้วกดปุ่ม **"👥 นำเข้ารายชื่อนักเรียน"** -> กด **"📥 ดาวน์โหลดไฟล์ตัวอย่าง CSV (Template)"**
2. เปิดไฟล์ใน Microsoft Excel หรือ Google Sheets แล้วกรอกรายชื่อนักเรียนโดยมีคอลัมน์ดังนี้:
   ```csv
   วิชา,ห้อง,เลขประจำตัว,ชื่อ-นามสกุล
   ฟิสิกส์ 1,ม.4/1,10001,นายกิตติศักดิ์ มีดี
   ฟิสิกส์ 1,ม.4/1,10002,นายชยกร สมพันธ์
   ฟิสิกส์ 1,ม.4/2,10005,นายณปกร สำอางค์
   ```
3. บันทึกไฟล์เป็นประเภท **CSV (Comma delimited) (*.csv)**
4. ในหน้าเว็บครู กดปุ่ม **"👥 นำเข้ารายชื่อนักเรียน"** -> เลือกไฟล์ CSV -> กด **"เริ่มนำเข้า"**
5. ระบบจะอัปเดตรายชื่อนักเรียนและวิชาใหม่ขึ้นหน้าเว็บให้อัตโนมัติทันที!

## ขั้นตอนที่ 4: การนำไปแสดงผลบน GitHub Pages

1. นำไฟล์ทั้งหมดในโฟลเดอร์นี้ไป Push ขึ้น GitHub Repository ของคุณ
2. ไปที่ตั้งค่า Repository บน GitHub: **Settings -> Pages**
3. ที่หัวข้อ **Build and deployment** -> เลือก Source เป็น `Deploy from a branch` -> เลือก Branch เป็น `main` / `master` -> กด Save
4. เว็บไซต์ของคุณจะออนไลน์และใช้งานได้ทุกอุปกรณ์ทันทีผ่านลิงก์ GitHub Pages!
